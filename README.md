# Udemy Home Page Clone (React)

A React version of the Udemy home page, built to practise components, props and layout.

## Sections (components)

| Component | What it shows |
|---|---|
| `navbar.js` | Logo, search box and "My Learning" menu with a popup |
| `catogery.js` | Category buttons, flash-sale banner and recommended courses |
| `topics.js` | "Topics recommended for you" section |
| `final__topics.js` | "Most popular" courses section |

## Tech Stack

- React 19 (Create React App)
- CSS

## Getting Started

**Prerequisites:** Node.js 18+ and npm

```bash
git clone https://github.com/BALASUBRAMANIYAN-S/project_of_udemy_react.git
cd project_of_udemy_react
npm install
npm start
```

The app opens at `http://localhost:3000`.

| Command | What it does |
|---|---|
| `npm start` | Run in development mode |
| `npm run build` | Build for production |
| `npm test` | Run tests |
